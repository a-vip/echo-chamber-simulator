## 🎮 The Premise & Social Satire

**The Echo Chamber Simulator** is a high-octane, satire-heavy management and balancing simulation game. You control the master recommendation algorithm for an increasingly unhinged, digitally addicted human species.

Instead of maximizing happiness or truth, you must harvest **Neuro-Watts (⚡)** and **Ad Revenue ($)** from collective outrage and ideological conflict. 

### The Core Tension:
* **Too Peaceful (Tension < 20%):** Users touch grass, close the app, plant tomato gardens, and log off. **Result:** You are fired by shareholders for reckless empathy (*The Great Apathy* ending).
* **Too Chaotic (Tension = 100%):** Factions take up arms, street wars break out, and the power grid is torn down (*Kinetic Civil War* ending).
* **Server Thermal Runaway (Core Temp = 100°C):** Too much ragebait and unskippable crypto ads melt the planetary datacenters into bedrock (*Planetary Server Supernova* ending).
* **The "Goldilocks Rot Zone" (65% – 92% Tension):** The sweet spot of societal agitation! While balanced in this zone, your Neuro-Watt harvest operates at a **5.0x Multiplier**!

## 🚀 How to Run & Embed

### 1. Launch in Browser (Zero Install)
Simply open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge). It works 100% offline with zero build steps or external dependencies.

### 2. Embed in Any Webpage or Obsidian Note (Iframe)
To embed into an existing website, blog post, or Obsidian canvas:
```html
<iframe 
  src="https://a-vip.github.io/echo-chamber-simulator/" 
  width="100%" 
  height="720px" 
  frameborder="0" 
  allow="autoplay"
  style="border-radius: 8px; border: 1px solid #3f3f46; box-shadow: 0 10px 25px rgba(0,0,0,0.5);">
</iframe>
```

For completely offline/single-file environments, use `dist/index.html` where all scripts and styles are 100% bundled into one file!

### 3. Launch Desktop Instance
On Windows, you can double-click:
```bat
run-game.bat
```
Or run the Python desktop launcher:
```bash
python launcher.py
```
This spawns a lightweight local HTTP server and automatically opens your game window.

### 4. Developer / Node Workflow
```bash
# Start local development server
npm start

# Rebundle single-file standalone distribution (dist/index.html)
npm run bundle

# Validate tests
npm test
```
